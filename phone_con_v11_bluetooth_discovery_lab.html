📡 Phone-Con v11: Bluetooth Discovery Lab

Goal: test what this browser can request, without pretending a browser page can turn the phone into a controller.

Test A: Web Bluetooth support

Checking browser capability…

This uses the browser's standard Bluetooth picker. It may be unavailable on Android Chrome, may require HTTPS, and will only show devices the browser is allowed to discover. It does not send controller inputs.

Test B: Gamepad API

Checking connected gamepads…

This checks controllers already connected to the phone. It does not search for or pair with the Switch 2.

Results

Ready. Run Test A, then Test B.

What the result means

  • Picker opens: browser Bluetooth discovery is available for some devices, not proof that Switch 2 accepts a phone connection.
  • API unavailable / error: this browser can't run this test. It does not prove Bluetooth hardware is absent.
  • No gamepads: the phone browser sees no gamepad input devices. This is separate from Bluetooth discovery.

Safety note: do not change developer settings or install apps for this test. Cancel the picker if the Switch 2 does not appear.
