1 · The three-layer map

Keep radio discovery, network/session management, and game-specific behavior separate. One layer succeeding does not prove the next one succeeds.

1
Radio / OS

LDN · Local Wireless

Advertisements, channel and network details, scanning, joining the wireless network, and system-level authentication. It requires low-level Wi-Fi capabilities that normal browser APIs don't expose.

Protocol documentedSplatoon specifics incomplete
2
Networking library

Pia · Session layer

Session discovery and lifecycle messages such as join requests, acknowledgements, responses, participant updates, and keepalive behavior. Exact encoding depends on protocol generation.

Multiple versions documentedDo not mix version layouts
3
Application

Splatoon · Game rules

Game-specific room details, allowed participants, lobby state, and match startup. A generic LDN or Pia library does not automatically implement this layer.

Must verify per game/version
LAN Play is a different route. Splatoon's special wired LAN Play mode uses IP networking and LAN discovery. Do not treat it as interchangeable with the Local Wireless LDN path mapped here.

3 · Raw byte inspector

Paste hexadecimal bytes or import a text/hex file from a capture tool. This displays offsets, byte values, and printable ASCII; it does not claim to decrypt or decode the LDN protocol.

Included starter bytes are synthetic. They spell “JoyGPT DEMO” in ASCII and are not copied from a Nintendo device or protocol capture.

File stays in your browser. This MVP accepts text containing hex bytes, not binary PCAP/PCAPNG files.

4 · Capture annotation checker

A separate note format for recording what you observed about a packet without pretending unknown fields have been decoded. This tool validates annotations, not Nintendo's binary protocol.

Expected structure: source, layer, version, notes, and a fields array. Each field gets a status of documented, inferred, or unknown. Do not put secrets, console identifiers, account details, or other private data in exported notes.

7 · What this lab does not solve yet

Not a live radio sniffer

Browser JavaScript on a normal webpage cannot receive arbitrary Wi-Fi action frames from the phone's built-in radio.

Not a PCAP decoder

Binary PCAP/PCAPNG parsing and protocol-specific cryptographic decoding are not included. Use a text hex dump or annotation JSON for this version.

Not a Splatoon client

No session join is sent, no authentication is performed, and no real lobby state is claimed.

Next research milestone: establish version-matched facts for Splatoon 2 and Splatoon 3 v11.3.0, then add a dedicated decoder only for packet formats that are actually documented or validated. Keep all unknown fields marked unknown.
