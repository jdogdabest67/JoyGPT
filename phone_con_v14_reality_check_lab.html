7 · Optional WebTransport endpoint

Requires an HTTPS HTTP/3 WebTransport server that you control. WebTransport is not a raw UDP socket. Skip this if you do not have such a server.

8 · Hard protocol limits

LDN Wi-Fi radio frames · NOT EXPOSEDNormal webpages cannot transmit arbitrary 802.11 action frames used by Switch local wireless.
Raw UDP broadcast · NOT EXPOSEDStandard webpage APIs do not provide general raw UDP sockets. WebTransport requires a compatible server and is not a LAN broadcast replacement.
Game join handshake · NOT ESTABLISHEDFinding a device or sending bytes does not prove the Switch accepts the required protocol, encryption, or game messages.
USB phone-to-Switch · ROLE-DEPENDENTAndroid showing file, tether, MIDI, photo, or charging modes does not mean the Switch accepts arbitrary phone-originated messages.
