🎮 Android → Switch controller bridge

Want the phone itself to act like a real Switch controller? That needs Android to advertise a Bluetooth game-controller device. A webpage cannot do that, so this is an external-app guide rather than fake “connected!” buttons.

Joy-Con Droid

A separate Android app project that aims to emulate Joy-Con/Pro Controller input, with Switch 2 support listed by its developers.

Read the official compatibility notes

Official releases page

Important compatibility warning

This is not a one-tap guaranteed solution. The project documentation says modern Switch firmware may require rooting Android and changing Bluetooth system behavior. Rooting can weaken security, break apps, or damage the phone’s software if done incorrectly, so this lab does not guide you through that.

What this page can do: test browser APIs and simulate touch controls locally. What it cannot do: turn those controls into a real Bluetooth controller or pair itself with the Switch 2.

🔵 Bluetooth Low Energy

Scans through the browser’s device picker, then optionally connects to a selected BLE device to inspect services allowed by the browser. This page acts as a Bluetooth client, not a Bluetooth HID controller.

🔌 WebUSB

Find a USB peripheral physically connected to the phone, usually through an OTG adapter. This inspects descriptors only. The phone and Switch console may both be USB hosts, so a cable alone does not make this webpage a controller.

🧩 WebHID

Discovers compatible HID peripherals if the browser and Android expose them. Chromium-based Android browsers generally do not implement WebHID, so a “not exposed” result is useful evidence, not a bug in this page.
