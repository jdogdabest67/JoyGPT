2. Local-play reality check

Splatoon 3's Salmon Run local wireless play is designed for 2–4 game clients running on Switch consoles. A browser page can't join that session merely by sending text: the game expects its own protocol, and browser JavaScript does not expose the console's local-play radio protocol.

The official game instructions describe joining through The Shoal by selecting the host's room on the console. This prototype is only a message-format experiment, not a working lobby joiner.
