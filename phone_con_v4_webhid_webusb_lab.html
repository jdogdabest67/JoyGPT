🧭 Switch 2 connection reality check

Web page → Bluetooth controller

WebHID does not make the phone advertise itself as a Bluetooth HID device. Standard browser APIs do not provide Bluetooth HID peripheral emulation.

Web page → USB controller

WebUSB lets a page talk to a USB device connected to the phone while the phone is acting as USB host. It does not turn the phone into a USB controller peripheral.

Useful experiments
